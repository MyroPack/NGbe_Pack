# Packs par défaut — NationsGlory Bedrock V2

Ce dépôt rassemble les packs de ressources par défaut utilisés par **NationsGlory Bedrock V2**. Il sert de point de référence pour retrouver les différents packs, consulter leurs fichiers et partager des informations utiles à leur modification.

## Contenu du dépôt

Les packs sont disponibles sous deux formes :

- **Dossiers décompressés** : fichiers consultables et modifiables (textures, modèles, sons, interfaces, définitions d’entités, etc.).
- **Archives `.zip`** : versions empaquetées des packs, pratiques pour les distribuer ou les importer.

Les dossiers et archives portant le même nom correspondent au même pack. Les archives sont disponibles [ici](https://github.com/MyroPack/NGbe_Pack/releases/tag/v2)

## Guides et fichiers d’aide

Des fichiers Markdown (`.md`) peuvent être ajoutés au dépôt pour documenter les packs et faciliter la recherche dans leurs ressources. Ils pourront notamment expliquer :

- quel fichier correspond à la texture d’un drapeau donné ;
- où se trouvent les textures, modèles, sons ou fichiers d’interface d’un élément ;
- à quel pack appartient une ressource ;
- les conventions de nommage ou les précautions à prendre avant une modification.

Les guides devront citer le chemin du fichier concerné, en partant de la racine du dépôt, afin que l’information soit facile à retrouver.
